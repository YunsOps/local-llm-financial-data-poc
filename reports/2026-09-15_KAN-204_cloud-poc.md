# KAN-204 Luna 동일 문항 비교 상세 시험 보고서

**Luna는 사전 지정한 영문 5문항에서 필수 항목 15/15를 충족했습니다.** 평균 응답 시간은 8.539초, 실제 사용량과 단가로 계산한 총비용은 USD 0.00375315입니다. 같은 문항에서 로컬 모델이 놓친 사실을 비교하되, 반복 수가 다른 소규모 시험이라는 범위 안에서 해석합니다.

[보고서 목록과 읽는 순서](README.md)

## S. 배경과 문제

로컬 모델의 오류가 나타났을 때, 같은 자료를 다른 실행 환경의 모델은 어떻게 설명하는지 비교할 기준이 필요했습니다. Luna를 Cloud 비교 모델로 두고, 로컬 시험 전에 지정한 영문 5문항을 동일한 원본과 계산식으로 채점했습니다. Luna의 답변을 정답으로 삼지는 않았습니다.

## T. 사전 질문과 기준

[평가 설계](2026-09-15_KAN-201_poc-design.md)에서 미리 지정한 Q01, Q03, Q06, Q08, Q10을 각 1회 실행했습니다. 입력, 지시문, 출력 JSON 형식과 문항당 세 가지 채점 항목은 로컬과 같습니다. 부분 설명과 누락은 0점으로 처리하고 이유를 남겼습니다.

Luna의 5개 응답과 로컬 모델별 같은 문항의 10개 응답을 비교했습니다. 반복 수가 다르므로 15점과 30점의 총점만 나란히 비교하지 않고, 충족 비율과 응답 수를 함께 제시했습니다. 시간, 토큰 사용량과 비용도 실제 기록이 있는 범위에서 비교했습니다.

### 측정 정의

Cloud 전체 응답 시간에는 네트워크 왕복과 최종 응답 수신까지의 대기가 포함됩니다. 서버 내부의 로딩 및 생성 단계별 시간과 VRAM은 측정하지 못했습니다. 로컬 시간은 모델 로딩을 포함하므로, 이 시간 비교는 사용자가 응답을 기다린 시간의 비교이며 모델 연산 속도만의 비교는 아닙니다.

토큰 수는 각 제공자가 반환한 사용량입니다. 모델마다 텍스트를 토큰으로 나누는 방식이 다르므로 같은 토큰 수를 같은 계산량으로 보지 않았습니다. 비용은 응답의 실제 사용량에 확인한 단가를 적용한 계산값이며, 청구서 확정 금액은 아닙니다. 로컬 소비전력과 전기요금은 측정하지 않았습니다.
