## 조건별 결과를 읽는 기준

- **기본 비추론:** 모델당 영문 20응답. Qwen 36/60점, Gemma 50/60점. 한국어 대응 3문항은 모델당 6응답으로 별도 비교.
- **기본 추론:** 생성 한도 2,048에서 모델당 12개, 4,096에서 Qwen 10개와 Gemma 9개 기록. 저장된 43개 모두 최종 답변 없이 길이 제한 종료. 중단 2개 및 미실행 계획과 구분.
- **권장 비추론:** 모델당 10응답. Qwen 17/30점, Gemma 22/30점.
- **권장 추론:** 모델당 10응답. Qwen 27/30점, Gemma 28/30점. 300초 내 지정 JSON은 각각 10/10회와 6/10회.
- **Luna:** 사전 지정 영문 5문항 한 번씩, 15/15점. 로컬의 전체 10문항 결과와 같은 분모의 순위로 해석하지 않음.

회고 점수는 Q07~Q10의 항목을 따로 보여주는 값이며 전체 점수에 이미 포함된다. partial과 fail은 모두 0점이지만 설명 일부 누락과 잘못된 주장은 구분해 기록했다. 점수는 요구한 사실의 충족률이며 최종 답변의 모든 문장이 정확하다는 뜻은 아니다.

문장 의미의 판정 주체는 Codex이다. 검사 코드는 출력 형식과 계산 가능한 거래 제한, 인용문과 입력 경로를 확인하고 검토 결과를 저장한다. 독립된 사람의 교차 검토를 수행한 평가로 표시하지 않는다.

권장 설정 추론에서 점수와 응답 완성이 개선됐으므로, 기본 설정의 도입 보류를 모든 설정에 일반화하지 않는다. 다만 권장 설정은 각 문항 한 번이고 일부 설명 오류와 응답 지연이 남아 실제 자동매매 도입 통과를 의미하지도 않는다.

## 보고서 작성과 보존 원칙

각 보고서는 **상황, 과제, 행동, 결과** 순서로 시험의 맥락과 결정 이유를 설명한다.

- 상황: 앞서 확인한 문제와 이번 시험이 필요한 이유
- 과제: 제공할 입력과 기대 결과, 평가 기준과 제외 범위
- 행동: 실제 실행 코드와 명령, 모델과 설정, 요청 및 원본 저장, 측정과 검토 방법
- 결과: 실제 응답과 판정 근거, 집계 대상 수, 잘못된 주장과 설명 누락, 활용 가능성과 한계

설정을 바꾸면 새 실험 ID로 기록한다. 이전 코드와 입력, 응답, 측정값은 그대로 보존하고 새 결과와 구분한다. 실패와 중단, 미실행, 미측정을 섞지 않으며 미측정을 0으로 채우지 않는다. 자동 검사를 실제 모델 호출이나 유료 API 사용량으로 집계하지 않는다.

상세 증빙에는 실행 당시 코드 원문이 포함되어 있다. 과거의 함수나 명령이 현재 코드에서 삭제된 경우에도 이력을 보존하며, 현재 재실행은 저장소 README의 명령을 따른다.
