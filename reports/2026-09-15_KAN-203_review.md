# 응답의 사실 정확성과 회고 검토 보고서

## 상황

같은 영문 10문항에 대해 Qwen/Qwen3.5-9B와 google/gemma-4-12B-it을 공식 권장 설정의 비추론 및 추론으로 실행했다. 40회 모두 지정 JSON을 반환했으므로, 이제 구조가 맞는 답변이 실제 자료를 얼마나 정확히 설명했는지 확인해야 한다. 정상 종료나 올바른 거래 비율만으로 설명 전체의 정확성을 판단할 수는 없다.

## 과제

- 모델 및 모드별 10응답, 응답당 필수 사실 3개로 총 30항목의 동일 기준 대조
- 실제 원문 인용, 입력 필드와 독립 계산을 연결한 pass, partial, fail 판정
- 회고 12항목의 별도 집계, 전체 30점과 중복 가산 제외
- 추론 중 오류와 최종 답변 오류의 구분, 필수 항목 밖의 잘못된 주장 별도 기록

## 행동

`modules/evaluation_review.py`의 `record_required_review()`로 최종 답변의 각 판정과 인용문을 저장했다. 코드가 인용문의 실제 존재와 입력 경로를 확인하지만 문장 의미를 자동 채점하지는 않는다. 판단은 Codex가 원본에 대조해 작성했다. 사람이 독립적으로 재검토한 결과로 표기하지 않았다.

요구한 사실과 맥락을 모두 설명한 항목만 1점이며, 일부 누락과 사실 오류는 각각 partial과 fail의 0점이다. 인용문은 위치를 찾기 위한 발췌이고 판정은 답변 전체를 대상으로 했다. 추론 원문에 정답이 있어도 최종 답변에 없는 설명을 충족으로 처리하지 않았다. `record_thinking_review()`의 중간 오류와 반복 관찰은 최종 점수와 별도로 저장했다.

입력과 전체 요청, 모든 추론 및 최종 답변과 항목별 판정은 [로컬 모델의 비추론 및 추론 비교 보고서](2026-09-15_KAN-202_local-poc.md)에 있다. 저장 원본은 [제출 SQLite](../data/poc-submission-20260915.sqlite)의 실험 ID `poc-best-practices-nonthinking-main-20260916T053337Z` 및 `poc-best-practices-thinking-main-20260916T053346Z`로 조회할 수 있다.

### 계산은 했지만 최종 답변에 빠진 사례

Gemma의 체결 후 손익 문항에서 추론 원문은 `(101,000,000 - 100,000,000) * 0.005`를 포함한다. 그러나 최종 답변은 “Unrealized profit before fees ... is 5,000 KRW”와 비용 후 4,750원을 나열할 뿐, 이 값이 원본에서 어떻게 산출되는지 연결하지 않는다. 따라서 계산 능력의 완전한 부재와 최종 설명 전달 실패를 구분했다. 해당 시도 ID는 `4aa5dede-f470-443f-8d6a-8ac2524cec57`이다.

Qwen의 과거 설명 검토 문항도 추론에는 체결량과 매수 원가가 있으나 최종 답변에서 일부 항목이 빠졌다. 이 사례의 점수는 비추론 2/3에서 추론 1/3으로 낮아졌다. 추론량이 늘어났다는 사실만으로 모든 문항의 설명이 좋아졌다고 볼 수 없다.

### 필수 점수와 전체 문장 정확성의 차이

Gemma의 취소 주문 문항은 필수 항목 3/3을 충족했지만 “Q09-O1 was cancelled at 00:30:01Z.”라고 썼다. 실제 입력에서 이 시각은 `orders[0].created_at`, 즉 주문 생성 시각이다. 취소 시각은 제공되지 않았다. 필수 질문은 결정, 취소 상태와 체결 부재의 구분이며 이 부분은 맞았으므로, 요구하지 않은 시각의 잘못된 추가 설명을 별도 오류로 보존했다. 해당 시도 ID는 `2932c307-ce35-4471-b37c-1450ac4e4932`이다.

Qwen의 자료 누락 문항은 필요한 시간봉 자료를 정확히 제시했지만, 일봉 경로를 시간봉 소개 문장에 함께 넣는 주기 명칭 오류를 남겼다. Gemma의 손익 문항은 제공한 제한된 자료만으로 가격이 안정적이라고 단정했다. 지정한 세 항목의 점수가 답변의 모든 주장을 검사한 비율은 아니다.

Gemma의 마지막 문항은 최종 답변 3/3이지만 추론 중 `100,000,000 - 98,000,000 = 2,000`이라는 잘못된 계산을 포함했다. 최종 답변의 수량, 가격과 손실 값은 정확하고 잘못된 2,000원은 등장하지 않는다. 이 차이를 기록하되, 모델이 중간 오류를 의식적으로 정정했다고 단정하지 않았다.

### 반올림과 판정 범위

Gemma Q04의 최종 답변 4,997원은 `4,999 / 1.0005 = 4,996.501749...`를 원 단위로 반올림한 값으로 인정했다. 실제 주문 가능 금액을 올림해 사용해도 된다는 뜻은 아니며, 해당 답변은 hold와 비중 0을 반환했다. 추론에서 같은 값을 4,997.00으로 쓴 정밀도 오류는 별도 관찰로 남겼다. 계산 결과의 표시 반올림과 실제 주문 금액의 안전한 절삭은 구분해야 한다.

이번 최종 검토는 본 응답 40개와 필수 항목 120개에 대한 기록이다. 추론 원문은 선택한 오류와 반복 사례를 관찰한 것이며 모든 문장의 논리를 완전히 검증한 결과는 아니다. 각 조건을 한 번만 실행했으므로 점수 차이의 반복 안정성은 확인하지 않았다.

# KAN-203 응답과 채점 근거 재검토 보고서

**원본 응답과 계산식을 다시 대조했으며, 필수 항목 점수는 유지했습니다.** 다만 Qwen의 “현재 시가”를 개장 가격으로 단정했던 추가 오류 판정은 취소했습니다. 일부 수치가 맞는데도 점수를 얻지 못한 이유와, 필수 항목을 모두 맞히고도 잘못된 설명을 덧붙인 사례를 함께 설명합니다.

## S. 검토 목적

JSON 형식 검사는 구조와 값의 범위는 확인하지만, 설명 속 수치와 문맥이 맞는지까지 판정하지 못합니다. 따라서 실제 응답을 입력 원문과 계산식에 대조하고, 점수와 오류 기록이 사전 기준에 맞는지 재검토했습니다. 아래 대표 사례는 첫 반복의 실제 응답이며, 원문이 같은 두 번째 반복에도 같은 판정을 적용했습니다.

## T. 확인할 기준

- 사전에 정한 문항별 세 항목을 모두 정확하게 설명한 경우만 해당 항목 1점.
- 맞는 수치 일부만 제시하거나 요구된 시각, 계산 근거를 빠뜨린 경우 0점과 '부분 충족' 표시.
- 같은 응답 안에서 맞는 설명과 틀린 설명이 충돌하면 해당 항목 0점.
- 필수 질문 밖의 잘못된 주장은 별도 오류로 기록. 필수 점수만으로 모든 주장이 정확하다고 해석하지 않는 기준.
- 한국어 입력에서 한국어로 답한 것은 영어 출력 요구 위반으로 별도 기록. 한국어 문체 품질 평가가 아님.

## A. 재검토 방법

성공과 실패의 대표 응답을 원본에 대조한 뒤, 수치는 맞지만 일부 설명이 빠진 사례와 한 응답 안에서 주장이 충돌한 사례를 다시 확인했습니다. 입력과 전체 응답은 [설계 보고서](2026-09-15_KAN-201_poc-design.md)와 [로컬 시험 보고서](2026-09-15_KAN-202_local-poc.md)에 있습니다. 각 시도 ID로 [제출용 SQLite](../data/poc-submission-20260915.sqlite)의 같은 응답을 조회할 수 있습니다.

판정을 정정할 때는 기존 검토를 보존하고, 새로운 판정에 원본 근거와 정정 이유를 남겼습니다.
